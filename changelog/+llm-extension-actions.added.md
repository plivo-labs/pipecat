- Added three actions an LLM extension can ask its service for, as it already asks it to push a frame: `BaseLLMExtension.run_function_calls()` runs function calls of the extension's own, `BaseLLMExtension.queue_frame()` queues a frame for the service to process, and `BaseLLMExtension.cancel_inference_in_progress()` cancels the service's inference for a context frame, if it is the one in progress.
